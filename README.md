# 🍽️ FOODVERSE – Smart Food Planner

**Eat Smart • Save More**

FOODVERSE is a Java Swing-based desktop application designed to make daily meal planning easier and more budget-friendly. It helps users discover recipes, plan meals, find recipes using available ingredients, compare cooking costs, and manage grocery items through an interactive graphical interface.

## 🚀 Features

### 🏠 1. Home Dashboard
- Displays a random daily food suggestion.
- Shows recipe statistics and estimated savings.
- Provides quick navigation to application modules.

### 🔍 2. Food Discovery
- Browse available food recipes.
- Search for recipes.
- Filter recipes by meal category.
- View ingredients and preparation instructions.

### 📅 3. Daily Meal Planner
- Generate meal suggestions for:
  - 🍳 Breakfast
  - 🍛 Lunch
  - 🥗 Snack
  - 🍽️ Dinner
- Compare home cooking costs with online food prices.
- Add selected meals to the grocery cart.

### 🥗 4. Smart Food Maker
- Enter ingredients available at home.
- Find recipes based on matching ingredients.
- Display available and missing ingredients.
- Calculate ingredient matching percentages.

### 💰 5. Price Comparison
- Compare estimated home cooking prices with online prices.
- View animated price comparison charts.
- Understand potential savings.

### 🛒 6. Grocery Cart
- Add food items to the cart.
- Increase or decrease item quantities.
- Remove items.
- Calculate the total estimated cost.

## 🛠️ Technologies Used

- **Programming Language:** Java
- **GUI Framework:** Java Swing
- **Libraries:** Java AWT
- **Concepts:** Object-Oriented Programming (OOP), Event Handling, Collections Framework
- **UI Design:** Custom components, gradients, rounded buttons, and animations

## 💻 Installation & Setup

### Prerequisites
- Java Development Kit (JDK)
- Any Java-supported IDE (IntelliJ IDEA, Eclipse, or VS Code)

### Step 1: Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

### Step 2: Open the Project

Open the project folder in your preferred Java IDE.

### Step 3: Compile the Application

```bash
javac -encoding UTF-8 FoodVerse.java
```

### Step 4: Run the Application

```bash
java FoodVerse
```
